### Current focus — HXARK

**[HXARK](https://hxark.com/)** is my AI agent platform for business tasks: research, content with images, documents, reports and scheduled workflows. Agents work in the cloud or through an optional Chrome extension, with activity and results visible in the conversation.

The web product is open to the public. It brings together connected accounts, browser actions and recurring tasks, so a request can become work someone can review and use.

[Try HXARK](https://hxark.com/) · [See real demonstrations](https://hxark.com/demonstracoes/)

### WoWHellgarve & SPP

I founded **[WoWHellgarve](https://wowhellgarve.com/)** and remain its **main developer**. My work spans WoW server emulation, custom gameplay systems, databases, launchers, crash investigation and the daily work of keeping a live community running.

I'm also a **developer on SPP — Single Player Project**, working on server behaviour, debugging, fixes and local builds. My work includes **[KyrianCORE / Shadowlands](https://github.com/coolzoom/KyrianCORE-OpenSource)**.

I started at 16 with Lineage II private servers. That grew into years of emulator development, runtime instrumentation, memory analysis and protocol research. The tools above are part of turning that work into something others can inspect and use.
